# 🍳 Recipe App

A modern Android application designed for exploring, searching, and saving delicious recipes from around the world. Built with **100% Kotlin**, **Jetpack Compose**, and **Material Design 3**.

---

## ✨ Features

- **Discover Dishes**: Browse curated and random meal recommendations.
- **Search**: Fast real-time recipe and ingredient search.
- **Meal Details**: Comprehensive recipe details including country of origin, categories, and step-by-step cooking instructions.
- **Save Favorites**: Bookmark your favorite recipes locally with offline persistence using Room Database.
- **Modern UI**: Full Material Design 3 (MD3) experience with dynamic theming and smooth animations.

---

## 🛠️ Tech Stack & Architecture

- **UI**: [Jetpack Compose](https://developer.android.com/jetpack/compose) & [Material Design 3](https://m3.material.io/)
- **Architecture**: MVVM (Model-View-ViewModel) + Repository Pattern
- **Networking**: [Retrofit 2](https://square.github.io/retrofit/) & Gson Converter
- **Local Database**: [Room Database](https://developer.android.com/training/data-storage/room)
- **Image Loading**: [Coil](https://coil-kt.github.io/coil/)
- **Navigation**: Navigation Compose
- **Async & Reactive**: Kotlin Coroutines & StateFlow
- **API Source**: [TheMealDB API](https://www.themealdb.com/)
